# 初中物理电路绘制与仿真

一个面向初中物理教学的电路绘制与仿真工具。用户可以在画布上放置电路元件、用导线连接成电路，程序会自动求解并显示各元件的电流、电压示数。

## 功能特点

- **丰富的电路元件**：电池（3V / 内阻 0.5Ω）、电池组（6V / 内阻 1.0Ω）、开关、灯泡、定值电阻、电流表、电压表
- **自由绘制电路**：点击面板元件添加至画布，按住右键拖拽连接导线（导线严格水平/垂直）
- **自动仿真**：元件移动、开关切换、导线增删后自动重新求解电路
- **实时示数**：电流表、电压表显示仿真读数，灯泡亮度随实际功率变化
- **短路提醒**：电池短路（或负载过大）时元件变为橙色警示，不会弹窗打断操作
- **开关交互**：单击切换开/闭状态，拖拽仅移动位置

## 电路求解原理

采用改进节点分析法（Modified Nodal Analysis, MNA），基于 numpy 求解线性方程组，支持含内阻电源、串并联混联电路。

## 环境要求

- Python 3.11+
- PySide6
- numpy

## 安装与运行

```bash
pip install PySide6 numpy
python main.py
```

## 打包为可执行文件

```bash
pip install pyinstaller
pyinstaller 初中物理电路绘制.spec
```

打包产物位于 `dist/初中物理电路绘制.exe`。

## 项目结构

```
physicshower/
├── main.py        # 主程序入口，主窗口布局与仿真调度
├── canvas.py      # 电路画布：元件管理、导线连接、节点识别
├── components.py  # 电路元件定义（基类及各元件的绘制与交互）
├── panel.py       # 右侧元件选择面板
└── solver.py      # 电路求解器（MNA + numpy）
```

## 使用说明

1. 点击右侧面板中的元件按钮，将其添加到画布
2. 在画布空白处按住鼠标右键拖拽，从元件端口拉出导线
3. 拖动元件调整位置，导线会自动跟随
4. 单击开关可切换通断状态
5. 电路变化后自动刷新仿真，观察各元件示数
